# Product

## Register

product

## Users

Application developers integrate the packages into web, desktop or native products. Operators and domain users then use the resulting chat to review agent work, answer questions, approve sensitive steps and interact with application artifacts such as publications, media, tables, charts, invoices or execution evidence.

## Product Purpose

Simplia Agent Chat provides one familiar interaction model for many agent-enabled applications without forcing them to share business logic, storage or authorization. Success means an application can adopt the protocol and shell, register its own surfaces and connect its own provider transport without copying the runtime or adding provider conditionals to the UI.

## Brand Personality

Familiar, precise, adaptable. The interface should feel immediately understandable to users of established agent chats such as DeepCode, T3Code and Codex while remaining visibly owned by the consuming application.

## Anti-references

- Markdown-only chat boxes that flatten tools, approvals and artifacts into transcript text.
- Monolithic components that combine transport, state, policy and presentation.
- Provider-specific UI branches scattered across application code.
- Ornamental AI dashboards, neon decoration, glass effects and gratuitous motion.
- Permission prompts that look like ordinary assistant messages.

## Design Principles

1. Make agent state and required human action unmistakable.
2. Keep familiar chat behavior while allowing application-native artifacts.
3. Treat provider capability, user permission and terminal completion as separate facts.
4. Fail safely and legibly when an event or surface is unknown.
5. Let the consuming application own brand, policy and domain actions.

## Accessibility & Inclusion

Target WCAG 2.2 AA. All core interactions must work with keyboard and screen readers, protect IME composition, provide visible focus, support coarse touch targets and respect reduced-motion preferences. Streaming updates must not repeatedly flood assistive live regions. Meaning cannot depend on color alone.
